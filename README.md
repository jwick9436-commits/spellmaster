## ✨ Features

- 🎯 **1,500+ Words** (500 Easy, 500 Medium, 500 Hard)
- 🎤 **Voice Test Mode** with text-to-speech
- 📊 **Spaced Repetition System (SRS)** for effective learning
- 🔥 **Streak Tracking** and performance metrics
- 🎨 **3 Themes** (Dark, Light, Cyberpunk)
- 👤 **User Accounts** with progress saving
- 📥 **Import Custom Word Lists**
- 💰 **Ad-Supported** (Google AdSense)
- 📱 **Fully Responsive** design

---

## 🎯 How It Works

1. **Practice** - Type words with definitions and sentence context
2. **Test** - Listen to audio and spell the word correctly
3. **Review** - Failed words go to SRS for extra practice
4. **Track** - Monitor your progress with detailed metrics
